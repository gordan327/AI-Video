# AI-Video 1.0 Release Notes

**Release:** 1.0.0  
**Date:** 2026-07-28

AI-Video 1.0 is the first stable release of the privacy-first video
anonymization application and framework.

## Highlights

- Desktop applications for macOS and Windows
- Command-line interface for configuration-driven processing
- SCRFD face detection
- ByteTrack face tracking
- Blur, pixelate, and solid-color anonymization
- Temporal privacy protection for intermittent missed detections
- Original audio preservation through FFmpeg
- Extensible detector, tracker, and renderer architecture
- 126 automated tests

## Downloads

The release is intended to provide:

- `AI-Video.app` for macOS
- `AI-Video-Windows.zip` for Windows
- Source archives generated by GitHub

The Windows archive is portable: extract it and run the included
application. The macOS application can be copied to the Applications
folder.

## Verification

The macOS application and Windows portable distribution have both been
tested successfully on their target operating systems. GUI startup,
video selection, the three privacy renderers, audio merge, cancellation,
and output generation were included in release verification.

## Known Limitations

- The first launch may take longer while AI model resources are prepared.
- Processing performance depends on video resolution, duration, and
  available CPU or GPU resources.
- Linux is supported through source installation but remains experimental.
- Batch processing and automatic updates are not included in Version 1.0.

## Privacy

AI-Video processes videos locally. Users remain responsible for protecting
original and processed videos and for complying with applicable privacy and
data-protection requirements.

## Next Steps

Version 1.1 may focus on usability improvements, expanded documentation,
performance work, additional plugins, and broader integration testing.
